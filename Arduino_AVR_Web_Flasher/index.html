1. เลือกบอร์ด & เชื่อมต่อ

ยังไม่ได้เชื่อมต่อ
⚠️ Mega2560 ใช้โปรโตคอล STK500v2 ซึ่งซับซ้อนกว่าและทดสอบมาน้อยกว่ากลุ่ม Uno/Nano ถ้าเชื่อมต่อหรือ flash ไม่สำเร็จ ให้ลองใช้ Arduino IDE อัปโหลดแทนไปพลางก่อน แล้วส่ง log ในกล่องด้านล่างมาให้ช่วยตรวจได้

2. เลือกไฟล์ .hex

ต้องเป็นไฟล์ .hex ที่ compile แล้ว (ไม่ใช่ไฟล์ .ino) — ได้จาก Arduino IDE: เมนู Sketch → Export Compiled Binary จะได้ไฟล์ .hex อยู่ในโฟลเดอร์เดียวกับ sketch

Arduino AVR Web Flasher v1.0 · พัฒนาโดย Thanee Kongkrapun
ใช้โปรโตคอล STK500v1/v2 ผ่าน Web Serial API เขียนขึ้นเองตามสเปกสาธารณะของ Atmel/Arduino ไม่มีการอัปโหลดไฟล์ .hex ไปเซิร์ฟเวอร์ใด ๆ ทุกอย่างเกิดขึ้นในเบราว์เซอร์เครื่องนี้เท่านั้น ต้องเปิดผ่าน https:// (หรือ localhost) ด้วย Chrome / Edge บนคอมพิวเตอร์
ยังไม่รองรับ: Arduino Leonardo/Micro/32u4 (bootloader คนละแบบ), Arduino UNO R4, Nano 33/Every/BLE, Due, Portenta
