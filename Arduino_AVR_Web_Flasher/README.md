# Arduino AVR Web Flasher v1.0

เว็บทูล flash ไฟล์ `.hex` (compiled) ให้บอร์ดตระกูล Arduino AVR ผ่าน USB ตรงจากเบราว์เซอร์
โดยเขียนโปรโตคอล **STK500v1** และ **STK500v2** ขึ้นเองผ่าน **Web Serial API** (ตามสเปกสาธารณะ
ของ Atmel/Arduino) — คนละกลไกกับทูล ESP32 (`esptool-js`) เพราะ AVR ใช้โปรโตคอลคนละแบบ

## รองรับบอร์ดอะไรบ้าง

| บอร์ด | โปรโตคอล | Baud | สถานะ |
|---|---|---|---|
| Arduino Uno / Nano (bootloader ใหม่, optiboot) | STK500v1 | 115200 | ทดสอบดีแล้ว |
| Arduino Nano (bootloader เก่า) / Pro Mini | STK500v1 | 57600 | ทดสอบดีแล้ว |
| Arduino Mega 2560 | STK500v2 | 115200 | **ทดลอง** — ดูหมายเหตุด้านล่าง |

### ⚠️ ยังไม่รองรับ
- **Arduino Leonardo / Micro / บอร์ดที่ใช้ชิป ATmega32u4** — ใช้ bootloader แบบ USB-CDC (Caterina)
  คนละกลไกกับ STK500 เลย ต้องเขียนโปรโตคอลแยกต่างหาก (avr109/Butterfly)
- **Arduino UNO R4, Nano Every, Nano 33 IoT/BLE, Due, Portenta** — ใช้ชิปและ bootloader คนละตระกูล
  (Renesas, SAMD21, SAM3X, nRF52840 ตามลำดับ) ไม่ใช่ AVR แล้ว

### หมายเหตุเรื่อง Mega2560 (สำคัญ)
โปรโตคอล STK500v2 ที่ bootloader ของ Mega2560 ("wiring") ใช้ มีรายละเอียดปลีกย่อยที่ไม่ได้เปิดเผย
เป็นมาตรฐานสาธารณะทั้งหมด (ต่างจาก STK500v1 ที่นิ่งและมีคนทดสอบซ้ำแล้วซ้ำเล่ามานาน) โค้ดส่วนนี้เขียน
ตามสเปก AVR068 ของ Atmel + พารามิเตอร์ที่ avrdude ใช้ทั่วไป **แต่ยังไม่ได้ทดสอบกับฮาร์ดแวร์จริงครบทุกกรณี**
ถ้าลองแล้วไม่ผ่าน ให้ใช้ Arduino IDE อัปโหลดไปพลางก่อน แล้วส่ง log จากกล่อง log ในหน้าเว็บ (หรือ
สกรีนช็อต) มาให้ช่วยตรวจแก้ต่อได้

## วิธีเตรียมไฟล์ .hex
ไฟล์ที่ต้องใช้ **ไม่ใช่** ไฟล์ `.ino` แต่เป็นไฟล์ `.hex` ที่ compile แล้ว:
1. เปิดสเก็ตช์ใน Arduino IDE
2. เมนู **Sketch → Export Compiled Binary** (หรือกด Ctrl+Alt+S)
3. จะได้ไฟล์ `.hex` อยู่ในโฟลเดอร์เดียวกับไฟล์ `.ino` นั้น (เช่น `MySketch.ino.hex`)
4. เอาไฟล์นี้มาเลือกในเว็บทูล

## วิธีใช้งาน
1. เลือกรุ่นบอร์ดให้ตรงกับที่มี
2. กด **"เลือกพอร์ต & เชื่อมต่อ"** เลือกพอร์ต USB ของบอร์ด
3. เลือกไฟล์ `.hex`
4. กด **"เริ่ม Flash"** — ระบบจะรีเซ็ตบอร์ดเข้า bootloader อัตโนมัติ, sync, แล้วเขียนข้อมูลทีละหน้า (page)
5. เสร็จแล้วบอร์ดจะรันโปรแกรมใหม่ทันทีเอง (ไม่ต้องกด reset เพิ่ม)

## โฮสต์ขึ้นเว็บจริง
เหมือนทูล ESP32 — อัปโหลด `index.html` ขึ้น GitHub Pages หรือ hosting ที่มี HTTPS ได้เลย

## Troubleshooting
- **เชื่อมต่อได้แต่กด Flash แล้ว error "sync ไม่สำเร็จ"** → บอร์ดอาจไม่ได้เข้า bootloader ตรงจังหวะ
  ลองกดปุ่ม RESET บนบอร์ดเองพร้อม ๆ กับกด "เริ่ม Flash" (จับจังหวะให้ reset ปล่อยตอนที่เพิ่งกด Flash)
- **error "STK500v2: sign-on ไม่สำเร็จ" (Mega2560)** → ลองกด "รีเซ็ตบอร์ด" ก่อน 1 ครั้ง แล้วค่อยกด
  "เริ่ม Flash" ใหม่ทันที, หรือลองสลับมาใช้ Arduino IDE ถ้ายังไม่ผ่าน
- **"ขนาดไฟล์ใหญ่กว่าพื้นที่ flash ของบอร์ดนี้"** → sketch ใหญ่เกินพื้นที่ของชิป ให้ลดขนาดโค้ด/ไลบรารี
  หรือเช็คว่าเลือกรุ่นบอร์ดถูกต้อง (Uno/Nano 328P มีพื้นที่จำกัดกว่า Mega2560 มาก)
- **บอร์ดที่ใช้ชิป USB-Serial ราคาถูก (CH340) ไม่ขึ้นในรายการพอร์ต** → ต้องลง driver CH340 ในเครื่องก่อน
