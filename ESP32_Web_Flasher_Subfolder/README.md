# ESP32 Web Flasher (self-hosted)

เว็บทูล flash ไฟล์ firmware `.bin` ให้ ESP32 / ESP32-S3 / ESP8266 ผ่านสาย USB
โดยทำงานในเบราว์เซอร์ล้วน ๆ (ใช้ **Web Serial API**) เหมือน esptool.spacehuhn.com
แต่ปรับให้:
- เพิ่มไฟล์ได้หลายไฟล์ พร้อมกำหนด **offset เอง** ทีละไฟล์
- มีปุ่ม preset offset มาตรฐาน (bootloader / partitions / boot_app0 / firmware)
- เลือก baudrate เอง, มี log terminal และ progress bar ต่อไฟล์

## วิธีใช้แบบเร็วที่สุด (ไม่ต้องโฮสต์ ทดสอบก่อนได้)
เปิดไฟล์ `index.html` นี้ผ่าน local web server (Web Serial ใช้งานไม่ได้ถ้าเปิดแบบ `file://` ตรง ๆ)

ตัวอย่างถ้ามี Python:
```bash
cd ESP32_Web_Flasher
python3 -m http.server 8080
```
แล้วเปิด `http://localhost:8080` ด้วย **Chrome หรือ Edge**

## วิธีโฮสต์ขึ้นเว็บจริง (ใช้ถาวรได้ทุกที่)
ต้องเป็น **HTTPS** เท่านั้น (ยกเว้น localhost ตอนทดสอบ) เพราะ Web Serial บังคับ secure context
ตัวเลือกที่ทำได้ทันที:

### แบบง่ายสุด — GitHub Pages (ฟรี)
1. สร้าง repo ใหม่บน GitHub
2. อัปโหลด `index.html` เข้าไป
3. ไปที่ Settings → Pages → เลือก branch `main` → Save
4. รอ 1-2 นาที จะได้ลิงก์ประมาณ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

### แบบใช้ hosting ที่มีอยู่แล้ว (เช่นของร้าน/โดเมนตัวเอง)
แค่อัปโหลด `index.html` ผ่าน FTP/cPanel ไปยังโฟลเดอร์ที่ให้บริการผ่าน HTTPS ก็ใช้ได้เลย
ไม่มี backend, ไม่มี database, ไม่ต้องตั้งค่า server เพิ่ม — เป็นไฟล์เดียวจบ

## วิธีใช้งานหน้าเว็บ
1. เสียบ ESP32 เข้าคอมด้วยสาย USB (ให้ลง driver CH340/CP2102 ให้เรียบร้อยก่อนถ้ายังไม่เคยลง)
2. กด **"เลือกพอร์ต & เชื่อมต่อ"** → เบราว์เซอร์จะเด้งหน้าต่างให้เลือกพอร์ต (นี่คือขั้นตอน "เลือกพอร์ต" ที่ทำได้ผ่าน Web Serial — ตัวเบราว์เซอร์เป็นคนโชว์รายชื่อพอร์ตให้เลือกเอง)
3. เพิ่มแถวไฟล์ที่ต้องการ flash ด้วยปุ่ม **"+ เพิ่มไฟล์"** หรือกดปุ่ม preset (เช่น `firmware @ 0x10000`) แล้วเลือกไฟล์ `.bin` ของตัวเองในแถวนั้น
4. ใส่ offset เป็น hex (เช่น `0x10000`) ให้ตรงกับที่ firmware กำหนด — ถ้าไม่แน่ใจ ให้เช็คจาก build log ของโปรเจค (PlatformIO/Arduino IDE จะบอก offset ตอน upload ปกติ)
5. กด **"เริ่ม Flash"** — จะเห็น progress bar วิ่งทีละไฟล์ และ log ด้านล่างแสดงสถานะ
6. เสร็จแล้วกด **"รีเซ็ตบอร์ด"** เพื่อให้บอร์ดรันเฟิร์มแวร์ใหม่ทันที (ถ้าไม่รีบูตเอง ให้กดปุ่ม RST บนบอร์ด)

## offset มาตรฐานที่ใช้บ่อย (ESP32 คลาสสิก, Arduino/PlatformIO ปกติ)
| ไฟล์ | Offset |
|---|---|
| bootloader.bin | 0x1000 |
| partitions.bin | 0x8000 |
| boot_app0.bin | 0xe000 |
| firmware.bin / app.bin | 0x10000 |
| merged/single .bin (รวมทุกอย่างแล้ว) | 0x0 |

> ESP32-S3 บางบอร์ด bootloader อยู่ที่ `0x0` แทน `0x1000` — ให้เช็คจาก build log ของโปรเจคนั้น ๆ
> ว่า esptool สั่ง flash ที่ offset ไหนบ้าง (มักจะเห็นตอน PlatformIO/Arduino IDE upload
> ผ่านสาย USB ปกติ)

## ความปลอดภัย / ความเป็นส่วนตัว
- ไฟล์ `.bin` ที่เลือกจะไม่ถูกอัปโหลดไปเซิร์ฟเวอร์ไหนทั้งสิ้น อ่านจากดิสก์แล้วส่งลง ESP32 ผ่าน USB โดยตรงในเบราว์เซอร์เท่านั้น
- ตัวเว็บโหลดไลบรารี `esptool-js` (ของทางการ Espressif) จาก CDN — ถ้าอยากให้ทำงานได้แม้ไม่มีเน็ต/อยากคุมเวอร์ชันเอง ให้ดาวน์โหลด `esptool-js` มาไว้ในโฟลเดอร์เดียวกัน แล้วแก้บรรทัด `import { ESPLoader, Transport } from "..."` ในไฟล์ `index.html` ให้ชี้ไปไฟล์ local แทน

## Troubleshooting
- **ปุ่ม "เลือกพอร์ต & เชื่อมต่อ" กดไม่ได้ / ขึ้นแจ้งเตือนสีแดง** → เบราว์เซอร์ไม่รองรับ Web Serial ให้ใช้ Chrome/Edge บนคอมพิวเตอร์
- **เชื่อมต่อไม่ติด/sync ไม่ผ่าน** → บางบอร์ดต้องกดค้างปุ่ม BOOT ไว้ตอนกด "เลือกพอร์ต & เชื่อมต่อ" (โดยเฉพาะ ESP32-S3 บางรุ่นที่ไม่มี auto-reset circuit)
- **Flash สำเร็จแต่บอร์ดไม่บูต** → เช็ค offset ให้ตรงกับที่ firmware ต้องการจริง ๆ, ลองติ๊ก "Erase All Flash" แล้ว flash ใหม่อีกรอบ
- **ไลบรารี esptool-js มีการอัปเดต API แล้วบางปุ่มพัง** (เช่นปุ่มลบแฟลชอย่างเดียว/รีเซ็ต) → เปิด Developer Console (F12) ดู error, โค้ดมีการ try/catch ไว้ให้ ฟังก์ชันหลัก (เชื่อมต่อ + flash) จะไม่ได้รับผลกระทบ
