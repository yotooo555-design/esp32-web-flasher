# RP2040 UF2 Flasher v1.0

เว็บทูลเขียนไฟล์ `.uf2` ให้บอร์ดตระกูล RP2040 (Raspberry Pi Pico, Pico W, และบอร์ด clone ที่ใช้ชิป RP2040)
ผ่านเบราว์เซอร์ล้วน ๆ โดยใช้ **File System Access API** — ไม่ใช้ WebSerial เพราะ RP2040 ตอนอยู่ใน
โหมด BOOTSEL จะแสดงตัวเป็น **ไดรฟ์ USB ธรรมดา** ให้ลากไฟล์ไปวางได้เลย เว็บนี้แค่ช่วยเลือกไฟล์+เขียนให้อัตโนมัติ

## รองรับเบราว์เซอร์
**Chrome หรือ Edge บนคอมพิวเตอร์เท่านั้น** (Firefox, Safari, และเบราว์เซอร์บนมือถือยังไม่รองรับ
File System Access API)

## วิธีใช้
1. ถอดสาย USB ของ Pico ออก
2. กดปุ่ม **BOOTSEL** ค้างไว้ แล้วเสียบสาย USB (หรือกด BOOTSEL ค้าง + กด RESET ถ้าบอร์ดมีปุ่มนี้)
3. ปล่อยปุ่ม — บอร์ดจะโผล่เป็นไดรฟ์ชื่อ **RPI-RP2**
4. เปิดเว็บนี้ กด **"เลือกไดรฟ์ RPI-RP2"** แล้วเลือกไดรฟ์นั้นในหน้าต่างที่เด้งขึ้นมา
5. เลือกไฟล์ `.uf2` ที่ต้องการ (ได้จาก compile MicroPython/CircuitPython/Arduino-Pico หรือดาวน์โหลดมา)
6. กด **"เขียนไฟล์ลงบอร์ด"** — รอจนขึ้น "เสร็จสมบูรณ์" บอร์ดจะรีบูตเข้าเฟิร์มแวร์ใหม่เอง

## โฮสต์ขึ้นเว็บจริง
เหมือนทูล ESP32 — อัปโหลด `index.html` ขึ้น GitHub Pages หรือ hosting ที่มี HTTPS ได้เลย
(ทดสอบ local ก่อนได้ด้วย `python3 -m http.server` แล้วเปิด `http://localhost:PORT`)

## Troubleshooting
- **กด "เลือกไดรฟ์" แล้วไม่เจอ RPI-RP2 ในรายการ** → บอร์ดอาจไม่ได้เข้าโหมด BOOTSEL จริง ลองถอดสาย
  แล้วทำตามขั้นตอนที่ 1-3 ใหม่ ให้แน่ใจว่ากด BOOTSEL ค้างไว้ตั้งแต่ก่อนเสียบสาย
- **เลือกโฟลเดอร์แล้วขึ้น "ไม่พบ INFO_UF2.TXT"** → เลือกโฟลเดอร์ผิด (ต้องเป็นตัวไดรฟ์ RPI-RP2 เอง
  ไม่ใช่โฟลเดอร์อื่นในเครื่อง) หรือบอร์ดไม่ใช่ RP2040 แท้
- **เขียนไฟล์ไม่สำเร็จ** → เช็คว่าไฟล์ `.uf2` ไม่เสียหาย (ลอง compile ใหม่), เช็คพื้นที่ว่างในไดรฟ์
  (ปกติไดรฟ์ BOOTSEL มีพื้นที่จำกัดตามขนาด flash ของบอร์ด)
